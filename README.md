# Anti Princess 👑🚫 (Hackathon Winner 🏆)

**Anti Princess** is a motivational app that uses "negative reinforcement" to build habits. If you don't complete your task (e.g., studying or exercising), the app triggers a penalty, such as a donation to an NGO or blocking social media.

## 🏆 Achievement
* **1st Place Winner** at Local Hackaton.
* Developed a functional MVP under high-pressure conditions.

## 🛠️ Tech Stack
* **Frontend:** React.js & CSS3.
* **Logic:** JavaScript (ES6+).
* **State Management:** React Hooks.

## ✨ Key Features
* **Commitment System:** Logic-based "fines" to ensure users reach their goals.
* **Task Management:** Users can set custom goals or receive random challenges.
* **Social Impact:** Redirecting missed goals into NGO contributions.

## 📈 Learning Journey
This project helped me master **React state management** and **JavaScript logic** while building a product from scratch in a limited timeframe.
